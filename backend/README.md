# BE-9 — Качество, безопасность, деплой

**Зависимости:** BE-6
**Оценка:** 1.5 дня
**Цель:** довести проект до состояния, в котором его не страшно выкатить.

Часть задач (тесты) выполняется параллельно с блоками BE-2…BE-6, а не в конце.

---

## BE-9.1 — Тестовая инфраструктура

- [ ] `pytest` + `pytest-django`, конфиг в `pyproject.toml`
- [ ] Фикстуры: `api_client`, `auth_client`, `user`, `product`, `cart_with_items`, `order`
- [ ] Фабрики на `factory-boy` для всех основных моделей
- [ ] `pytest-cov`, порог покрытия 80% (для `orders` — 85%)

**Приёмка:** `pytest` проходит на чистой БД, тесты не зависят друг от друга и от порядка запуска.

---

## BE-9.2 — Критичные тест-кейсы

- [ ] **Деньги:** расчёт доставки (порог бесплатной, экспресс), итоговая сумма, начисление баллов
- [ ] **Остатки:** конкурентное оформление двух заказов на последнюю единицу товара
- [ ] **Атомарность:** ошибка в середине оформления → полный откат
- [ ] **Изоляция:** чужой заказ / адрес / чат → 404
- [ ] **Авторизация:** доступ к приватным эндпоинтам без токена → 401
- [ ] **Валидация:** отрицательное количество, `quantity > stock`, пустая корзина
- [ ] **Идемпотентность:** повторная оплата, повторный сидинг
- [ ] **N+1:** `assertNumQueries` на каталоге и списке заказов

**Приёмка:** каждый пункт покрыт как минимум одним тестом.

---

## BE-9.3 — Аудит безопасности

- [ ] `python manage.py check --deploy` без предупреждений на прод-настройках
- [ ] Цены и суммы никогда не берутся из тела запроса клиента
- [ ] `sender_type`, `status`, `legality_points`, `payment_status` — не редактируются через API
- [ ] Rate limiting на `login`, `register`, `chat`, `reviews`
- [ ] Валидация загружаемых файлов (тип, размер), media-файлы отдаются не из Django на проде
- [ ] Секреты только в `.env`, `.env` в `.gitignore`, ключи ротируются
- [ ] Проверка зависимостей на уязвимости (`pip-audit`)

**Приёмка:** чек-лист пройден целиком и зафиксирован в PR.

---

## BE-9.4 — Производительность

- [ ] Проверить индексы под реальные фильтры каталога
- [ ] Кэширование `/categories/` и `/countries/` (Redis или локальный кэш)
- [ ] Ограничить максимальный `page_size` (защита от `?page_size=100000`)
- [ ] Генерацию PDF-сертификатов перевести в фоновые задачи, если превышает 1 сек

**Приёмка:** `/api/v1/products/` отвечает менее чем за 200 мс на 1000 товарах.
