## 🏛 О проекте

**«ЛЕГАЛЬНО.МАРКЕТ»** — это специализированная e-commerce платформа, ориентированная на продажу исключительно разрешенных к обороту товаров с прозрачной юридической чистотой, выдачей электронных «Сертификатов легальности» и расчетом доставки в 63 страны мира.

### Ключевые особенности платформы:

- 🛡 **Сертификат легальности** к каждому заказу (с уникальным номером документа и протоколом проверки).
- 💳 **Карта легального покупателя** (`LM-24-XXXXXX`) с начислением очков легальности (кешбэк за покупки и отзывы).
- 🌍 **Международная доставка в 63 страны**: калькулятор сроков, стоимости и таможенных условий.
- 💱 **Мультивалютность**: динамический пересчет цен (₽ Рубль, $ Доллар, € Евро).
- 📱 **Полная мобильная адаптивность**: мобильная нижняя навигация, всплывающие шторки разделов доставки и FAQ.

## ⚡ Инструкция по запуску

### 1. Запуск Frontend (клиент)

```bash
cd frontend

# Установка зависимостей (если еще не установлены)
npm install

# Запуск в режиме разработки (порт 3000)
npm run dev

# Или сборка и запуск продакшен-версии
npm run build
npm run start
```

Фронтенд откроется по адресу: [http://localhost:3000](http://localhost:3000)

---

### 2. Запуск Backend (API)

```bash
cd backend

# Активация виртуального окружения
source venv/bin/activate

# Применение миграций базы данных
python manage.py migrate

# Запуск dev-сервера (порт 8000)
python manage.py runserver 8000
```

API и админка будут доступны по адресу:

- Панель администратора: [http://localhost:8000/admin/](http://localhost:8000/admin/)
- Задачи и план бэкенд-разработки подробно описаны в [`backend/README.md`](file:///home/joy/legal_market/backend/README.md).

## 🛠 Реализованный функционал

| Раздел      | Возможности                                                                                                                                                |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Главная** | Промо-баннеры, hero-слайдер, быстрый переход по круглым категориям, сетка рекомендаций, карусель скидок недели                                             |
| **Каталог** | Двухуровневый выбор категорий на десктопе, боковое меню, поиск по названию/артикулу, 6 видов сортировки, адаптивная сетка                                  |
| **Товар**   | Галерея фото с превью, динамический калькулятор доставки по странам, протокол легальности, характеристики, отзывы, похожие товары                          |
| **Корзина** | Изменение количества, удаление, выбор стандартной или экспресс-доставки, расчет бесплатной доставки от 5 000 ₽                                             |
| **Чекаут**  | Форма данных получателя с валидацией, выбор способа оплаты (Карта / СБП / Крипта), генерация именного электронного сертификата легальности                 |
| **Профиль** | Карта легального покупателя, баллы, статистика, разделы: «Мои заказы», «Мои отзывы», «Стать продавцом», «Чаты», «Уведомления», «Настройки валюты и страны» |
| **Инфо**    | Условия доставки и таможни по 63 странам мира, интерактивный FAQ (аккордеоны)                                                                              |
